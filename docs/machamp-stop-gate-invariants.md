## Evidence classes

- **Verified locally:** deterministic filesystem, PostgreSQL and mock-backed
  behavior exercised in this repository.
- **Verified against unchanged Elephant consumers:** verbatim fixed reader
  projections execute against the generated Parquet without changing Elephant.
- **Deferred to controlled Filebase verification:** returned provider CID,
  provider limits/costs, upload receipts, public resolution and IPNS mutation.
- **Unresolved:** any row still marked pending or externally blocked above.
