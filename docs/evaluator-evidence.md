## Clean-browser procedure

1. Use a fresh browser profile with no local storage, extensions, repository tooling or localhost dependency.
2. Open the public explorer without credentials.
3. Show service version, contract hash, source coverage, run counts/deltas and limitations.
4. Show open-data and query publication references and independently resolve them.
5. Search within five miles of Zephyrhills for roof signals older than 15 years.
6. Search for open roofing permits ordered by deterministic duration.
7. Open property and permit evidence, including explicit unavailable BBB/ownership facts where applicable.
8. Inspect MCP discovery and confirm only six `prism_v1_*` tools.
9. Exercise body, radius, page, response and deadline bounds.
10. Record whether rate limiting is platform-native/distributed or instance-local/best-effort. Never claim distributed enforcement without proof.
11. Disconnect local Restate/PostgreSQL and repeat the hosted query.

## Real-data and publication proof

- Production configuration rejects fixture records and `fixture://` evidence.
- Real facts show public-source URLs/artifact hashes, collection timestamps and publication CIDs.
- Dry-run hashes are not represented as final Filebase CIDs.
- Partial source or county coverage is labeled with exact achieved counts/window.
- Missing BBB, roof or ownership evidence remains unavailable.

## Security and privacy proof

- `/health` contains no secrets or internal connection strings.
- Logs omit credentials, auth headers, session identifiers and unnecessary owner/contact fields.
- Public MCP is read-only and accepts only bounded structured inputs.
- Public owner/contact data is limited to the owner-approved, source-backed publication scope.
